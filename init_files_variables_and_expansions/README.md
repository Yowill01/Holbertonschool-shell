# Shell, init files, variables and expansions

This project contains shell scripts about init files, variables and expansions.

## Scripts

- `0-alias`: creates an alias named `ls` with the value `rm -f *`.
- `1-hello_you`: prints `hello user`, where user is the current Linux user.
- `2-path`: adds `/action` to the end of the `PATH`, so it is the last directory the shell looks into.
- `3-paths`: counts the number of directories in the `PATH`.
- `4-global_variables`: lists the environment variables.
- `5-local_variables`: lists all local variables, environment variables and functions.
